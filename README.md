# NFC Keyboard

Este es un proyecto inicial de React Native con Expo para desarrollar una aplicación móvil que use NFC.

## Arranque rápido

1. Instala dependencias:
   ```bash
   npm install
   ```
2. Inicia la app:
   ```bash
   npm run start
   ```
3. Para Android:
   ```bash
   npm run android
   ```

## Notas

- Esta plantilla usa Expo para el desarrollo móvil.
- El soporte NFC se debe implementar en la app mediante librerías nativas.
- Confirma si deseas avanzar con Expo o React Native CLI.
